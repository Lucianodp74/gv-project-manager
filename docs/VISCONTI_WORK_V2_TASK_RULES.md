# Visconti Work V2 — Regole operative delle attività

## Una attività deve sempre rispondere a 5 domande
1. Cosa bisogna fare?
2. Chi è responsabile?
3. Entro quando?
4. In che stato è?
5. Qual è il prossimo passo?

## Stati
- Da fare
- In corso
- In attesa
- Bloccata
- Completata
- Annullata

## Priorità
- Bassa
- Normale
- Alta
- Urgente

## Regola di attenzione
- scaduta → rossa
- scadenza entro 3 giorni → urgente
- bloccata → evidenza immediata
- completata/annullata → fuori dalle criticità

## Collegamenti
Un'attività può essere collegata direttamente a:
- un progetto;
- una pratica di connessione;
- una richiesta specifica di un ente;
- una fase tecnica o documentale.

## Ruoli
L'assegnatario esegue. Il responsabile di progetto coordina. Il supervisore controlla. Antonio interviene sulle decisioni e sulle eccezioni, non sulla micro-gestione.
